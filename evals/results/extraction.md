# Story extraction eval

Written by `npm run eval -- evals/extraction`; `npm run eval:rerender -- extraction` rebuilds it from the
rows stored below. Do not edit by hand. A run replaces the rows of the model and effort it ran; other rows stay.
Latency and cost are for one item run; a range in brackets is the lowest and highest repeat; pts are the
difference against the baseline row of the same run, with its 95% interval. See evals/README.md.

The extractor on 58 past issues (2026-09-15 to 2026-11-09) of tldr, rundown_ai, ai_breakfast, world_of_ai, the_signal: their public web versions (`evals/extraction/manifest.json`, chosen by `evals/extraction/find-issues.ts`), built into text by `evals/extraction/build-dataset.ts` with the repo's own helpers (beehiiv reader, `htmlToText`, tracking-link resolver) into `evals/data/extraction/` (gitignored). Production reads the email sources' plain-text part, so the text is close to, not the same as, what production sees. AlphaSignal has no public issue archive and is not in the set.

Golden (`evals/extraction/golden.json`, by Claude Opus from the issue text by the prompt's own rules, `evals/extraction/golden-todo.md`): per issue, the stories a perfect extraction returns (label, url, category, importance) and the items it must leave out.

Issues: per issue run. Valid output: the call returned stories matching the schema (two tries, as in production). All story URLs in text: every non-empty url is a link in the text (compared cleaned). No duplicates: by cleaned url or headline. Golden URLs found: golden stories with a url that the run returned (cleaned), with no judge.

The judge (the Judge column gives each row's model and effort; rubric in `evals/extraction/judge.ts`) matches each extracted story to a golden story, or calls it a roundup item, filtered, merged, a fragment or extra. Recall = golden stories matched (a roundup split into items counts as found). Precision = extracted stories that are one golden story, over all but roundup items. Category, Importance within 1 and URL are compared with the matched golden story. Faithful = no fact the text does not state, and Headline rules, are still the judge's, over every extracted story.

Saved per issue: stories with a usable link, as ingestion saves them. Dev DB: the Neon dev branch `stories` rows of the same source and day, which the production or n8n extractor made from the email (The Signal 2026-10-25 is under n8n's `tldr_ai` label); issues with fewer than 3 such rows have none. Dev DB URLs found: those rows' links that this run also saved.

p50/p95 time the extraction call alone.
