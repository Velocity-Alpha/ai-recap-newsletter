# Story extraction eval

Written by `npm run eval -- evals/extraction`. Do not edit by hand. A run replaces the rows of the model and
effort it ran; other rows stay. Latency and cost are for one item run. See evals/README.md.

The extractor on 12 past issues (2026-10-08 to 2026-11-08) of tldr, rundown_ai, ai_breakfast, world_of_ai, the_signal: their public web versions (`evals/extraction/manifest.json`), built into text by `evals/extraction/build-dataset.ts` with the repo's own helpers (beehiiv reader, `htmlToText`, tracking-link resolver) into `evals/data/extraction/` (gitignored). Production reads the email sources' plain-text part, so the text is close to, not the same as, what production sees. AlphaSignal has no public issue archive and is not in the set.

Issues: per issue run. Valid output: the call returned stories matching the schema (two tries, as in production). All story URLs in text: every non-empty url is a link in the text (compared cleaned). No duplicates: by cleaned url or headline.

Judge (gpt-6-sol, medium effort, rubric in `evals/extraction/judge.ts`) counts per run: Recall = qualifying stories in the text the extraction covers. Precision = extracted stories that are one real story (not sponsored, filtered, merged or a fragment). Faithful = no fact the text does not state. Headline rules and URL right follow the prompt. Category right and Importance within 1 are over the judge's real stories. Missed per issue is the judge's count.

Saved per issue: stories with a usable link, as ingestion saves them. Dev DB: the Neon dev branch `stories` rows of the same source and day, which the production or n8n extractor made from the email (The Signal 2026-10-25 is under n8n's `tldr_ai` label; In the World of AI 2026-10-22 has none). Dev DB URLs found: those rows' links that this run also saved.
