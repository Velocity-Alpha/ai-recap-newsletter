# Issue writer eval

Written by `npm run eval -- evals/writer`; `npm run eval:rerender -- writer` rebuilds it from the
rows stored below. Do not edit by hand. A run replaces the rows of the model and effort it ran; other rows stay.
Latency and cost are for one item run; a range in brackets is the lowest and highest repeat; pts are the
difference against the baseline row of the same run, with its 95% interval. See evals/README.md.

The issue writer on 30 issues (2026-04-01 to 2026-11-09; evals/writer/manifest.json), built by evals/writer/build-dataset.ts from the Neon dev branch (read-only) as drafting builds the writer's input. Sections and board order: issue_stories (the sent email) for published issues, the board's commit for 2026-11-09 (a draft, the only issue with a board commit).

Article text for the 195 feature stories: 7 saved copies (story_articles), 152 read by the repo's article reader on the build day, 36 not read (summaries only).

No issue had owner notes, so the eval adds 3 of its own to each issue (evals/writer/notes.ts), each checked in code.

Every metric reads the first draft, except "Checks pass after rewrite", which runs production's one rewrite. Cost per call and p50/p95 include the rewrites; p50/p95 are the writer calls alone (the writer times out at 240 s in production).

The judge grades each first draft against the writer's exact input (evals/writer/rubric.ts, which imports the writer's rules from writer.ts): unsupported claims counted per story, each bullet, each note, and editorial quality on anchored 1-5; (judge) counts are over the graded runs.

Golden: for each issue, a reference issue written by Claude Opus from the writer's exact input and instructions (evals/data/writer/golden.json, not committed; evals/writer/golden-todo.md). The pairwise judge compares each first draft with it, blind and in random order, without the article text; "vs golden" counts are over the graded runs, and a run that errored is a loss. Since the reference is fixed, win rates compare across efforts and models. They are relative, not a quality score: GPT-6 Luna drafts beat the Opus reference, which suggests the judge, an OpenAI model, may favour its own family's style.
